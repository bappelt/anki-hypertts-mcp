Lets Claude (or any other MCP client) add audio to your notes using your HyperTTS presets. Ask Claude to generate audio for a note, and the bridge does exactly what HyperTTS's own Apply To Notes button does: it reads the preset's source field, generates speech with the preset's voice, and puts the sound into the preset's target field.

Presets stay in HyperTTS: set up voices and fields there as usual, then use them from Claude.

What you need

  • HyperTTS, installed and enabled, with at least one preset.
  • This add-on.
  • The HyperTTS MCP Bridge extension for Claude Desktop (the .mcpb file), from the latest release on GitHub. Other MCP clients can run the server directly; see the project page.
  • An Anki MCP server, such as Anki MCP Server - AI Assistant Integration, so Claude can find your notes. Technically it's optional: the bridge identifies notes only by their note id, so without one you'd have to give Claude each note's id yourself, copied from Anki's Browser.

Anki must be running with a profile open whenever Claude uses the bridge.

Setup

  • Install this add-on and restart Anki. A tooltip confirms the bridge is listening.
  • Double-click the .mcpb file, and Claude Desktop asks to install it. (Or drag the file into Claude Desktop's Settings → Extensions.) To upgrade later, install the newer .mcpb the same way.
  • Ask Claude something like "Add pronunciation audio to my 'good morning' card using my Basic Ukrainian preset."

Tools Claude gets

  • list_hypertts_presets: lists your HyperTTS presets.
  • generate_hypertts_audio: generates audio for a note with a preset, chosen by name or id. It can also speak different text than the note's source field.

Configuration

Go to Tools → Add-ons → HyperTTS MCP Bridge → Config, and restart Anki after changes.

  • host: keep at 127.0.0.1.
  • port: default 8766. If you change it, change the Bridge URL in the extension's settings to match.
  • api_key: optional. Set it to a long random string, and enter the same value as the extension's Bridge API key.
  • max_text_override_chars: the longest custom text Claude may send, default 2000.

Privacy and security

The bridge only accepts connections from your own computer, and it refuses requests from web browsers, so websites can't use it. Text is sent to whichever text-to-speech service your HyperTTS preset uses, exactly as when you use HyperTTS directly.

Compatibility

Requires Anki 23.10 or later. Tested with HyperTTS 3.7.1.

The bridge works by calling HyperTTS's internals, which aren't a public interface, so a HyperTTS update could break it. If audio generation stops working after you update HyperTTS, check for an update to this add-on. This is an independent project, not made by or affiliated with the HyperTTS developers.
